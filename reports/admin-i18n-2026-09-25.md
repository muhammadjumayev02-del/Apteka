# Admin panel: dizaynni tiklash va ikki til

Git tarixi ushbu ish nusxasida mavjud emas. Dizayn `reports/admin-theme/1440-0.png` va `1440-2.png` dagi avvalgi ko‘rinish bilan solishtirildi: yig‘iladigan/guruhlangan menyu yana ochiq bir qatorli menyuga, dori formasi barcha maydonlari ko‘rinadigan avvalgi tartibiga qaytarildi. Katta tezkor tugmalar olib tashlandi; ularning amallari oddiy havolalar orqali saqlandi. Hisobotlar, jadval, ruxsatlar, sotuv va ko‘chirish funksiyalari saqlandi.

Django `LocaleMiddleware`, `set_language`, `gettext_lazy`, template `translate` / `blocktranslate`, standart `.po` / `.mo` kataloglari ishlatiladi. `O‘zbekcha | Русский` tugmalari POST/CSRF orqali tilni tanlaydi, joriy yo‘l va query parametrlarini saqlaydi; tanlov cookie orqali keyingi sahifalarga o‘tadi. Tashqi manzilga yo‘naltirish Django tomonidan rad etiladi.

Django admin/auth ichki matnlari va JavaScript vidjetlarining o‘zbekcha tarjimalaridagi bo‘shliqlar loyiha katalogida to‘ldirildi. Django yaratadigan standart ruxsat nomlari faqat ko‘rsatishda tarjima qilinadi. Dori nomlari, partiya raqamlari, hisoblar, guruhlar va boshqa bazadagi ma’lumotlar o‘zgartirilmadi. Joylashuvning tarjima qilingan ko‘rinishi imzolangan sotuv ma’lumotlari va saqlanadigan ko‘chirish tarixiga ta’sir qilmasligi uchun avvalgi barqaror qiymat alohida saqlandi.

## O‘zgartirilgan fayllar

- `config/settings.py`, `config/urls.py`: til middleware’i, tillar, tarjima kataloglari, til almashtirish URL’i.
- `catalog/admin.py`: avvalgi to‘liq dori formasi, tarjima qilinadigan admin nomlari va standart ruxsat yorliqlari.
- `catalog/models.py`, `catalog/apps.py`, `catalog/forms.py`, `catalog/dashboard.py`: model/maydon nomlari, validatsiyalar, tanlovlar va holatlar tarjimasi.
- `catalog/views.py`, `catalog/services.py`: interfeys xabarlari tarjimasi; joylashuvning avvalgi saqlanadigan qiymatini saqlash.
- `templates/admin/base_site.html`, `pharmacy_navigation.html`, `pharmacy_index.html`: til tanlash, menyu va bosh sahifa.
- `templates/language_switcher.html`: umumiy til almashtirish formasi.
- `templates/base.html`, `templates/catalog/*.html`, `templates/registration/login.html`, `templates/403.html`, `templates/404.html`: admin orqali ochiladigan amallar/formalar va umumiy interfeys tarjimasi.
- `static/catalog/admin.css`, `app.css`, `app.js`: tiklangan admin ko‘rinishi, til tugmalari va tarjima qilinadigan jonli qidiruv xabarlari.
- `locale/uz/LC_MESSAGES/django.po`, `django.mo`, `djangojs.po`, `djangojs.mo`; `locale/ru/LC_MESSAGES/django.po`, `django.mo`: tarjimalar. Ruscha standart Django va JavaScript tarjimalari Django’ning o‘zidan olinadi.
- `catalog/migrations/0007_alter_placement_batch.py`: faqat partiya maydonining interfeys nomi (`Batch` → `Partiya`) metadata migratsiyasi; mavjud yozuvlar o‘zgartirilmaydi.
- `catalog/test_admin_i18n.py`: ikki til, barcha admin sahifalari, saqlash/o‘chirish xabarlari, validatsiya, tilni saqlash, CSRF, tashqi redirect himoyasi va kiritilgan nomlarni saqlash testlari.
- `scripts/compile_translations.py`: GNU gettext o‘rnatilmagan muhit uchun standart PO → MO kompilyatori. GNU gettext bo‘lsa, odatdagi `manage.py compilemessages` ham ishlaydi.

## Tekshiruvlar

- `manage.py test --noinput`: 60 ta test o‘tdi.
- `manage.py check`: xatolik yo‘q.
- `manage.py makemigrations --check --dry-run`: qo‘shimcha migratsiya kerak emas.
- Asosiy va ichki admin sahifalari ikkala tilda: ro‘yxat, qo‘shish, tahrirlash, tarix, o‘chirish tasdig‘i, foydalanuvchi/guruhlar, parol, jadval, smena tafsilotlari va sotuvni bekor qilish.
- Google Chrome, 1440 px va 390 px: til tugmalari, joriy filtrli URL’ni saqlash, dori/partiya/xodim formalari, smenalar, jadval, sana tanlash va ruxsat vidjetlari. JavaScript xatosi yo‘q; mobil bosh sahifada gorizontal chiqib ketish yo‘q.
- Brauzer tekshiruvlari vaqtinchalik test bazasida bajarildi. Asosiy `db.sqlite3` o‘zgartirilmadi.

Skrinshotlar: `/tmp/apteka-browser-i18n/`. Tarjimalarni qayta kompilyatsiya qilish: `.venv/bin/python scripts/compile_translations.py`.
